# v0.2.0 (게이트)

기준: `Doc/RoadMap_v1.md`의 v0.2.0  
출발점: v0.1.0

## 1. 목표

점검 머신에서 `gostodian run`을 한 번 실행하면 홈랩 게이트의 `status`만 실행되고, 그 결과가 이력에 남는다. 목록 밖 동사, 허용 목록 밖 이름, 추가 인자는 게이트가 거부한다.

## 2. 구현 내용

- `gostodian-agent` → `gostodian-gate`
- `authorized_keys`의 `restrict,from="<점검머신 VPN IP>",command="/usr/local/bin/gostodian-gate"`
- 게이트 입력 `SSH_ORIGINAL_COMMAND` = `동사 [이름]`. 고정 동사, 허용 목록과 정확히 일치하는 이름만 통과. 그 외는 거부와 거부 로그
- 동사 `status`(호스트 기본 정보), `boot-id`. 읽기 전용

## 3. 상세 구현 내용

### 3.1 `gostodian-gate`

**구현**

- `cmd/gostodian-agent` → `cmd/gostodian-gate`. 바이너리 경로 `/usr/local/bin/gostodian-gate`
- 유지: 홈랩 상주 데몬 없음. SSH `command=`로 들어올 때만 실행
- `internal/ssh`의 원격 명령은 고정 경로 실행 → `status`. 이력의 명령은 `status`
- 셸 문자열 조립 없음

**완료**

- [x] `gostodian run` 한 번에 게이트 `status` 결과가 이력
- [x] 원격 명령 문자열이 셸로 조립되지 않음

### 3.2 `authorized_keys`

**구현**

- 홈랩 `authorized_keys` 한 줄: `restrict,from="<점검머신 VPN IP>",command="/usr/local/bin/gostodian-gate"`
- 등록 자체와 홈랩 방화벽(VPN → 22번만 허용, 점검 머신 퍼블릭 22번 차단)은 로드맵 운영 준비. 코드 밖
- 클라이언트가 보낸 명령은 `SSH_ORIGINAL_COMMAND`로만 전달. 게이트 바이너리 밖의 명령은 실행되지 않음

**완료**

- [x] 허용된 VPN 주소가 아니면 게이트가 실행되지 않음
- [x] `command=` 밖의 원격 명령은 실행되지 않음

### 3.3 동사와 이름

**구현**

- 입력은 `SSH_ORIGINAL_COMMAND` 하나. 형식은 `동사` 또는 `동사 이름`
- 동사는 고정 목록과 일치할 때만 통과
- 이름은 홈랩 허용 목록과 정확히 일치할 때만 통과. 부분 일치, 추가 인자, 빈 명령은 거부
- 거부 시 종료 코드 비영, 거부 로그. 거부된 문자열은 실행하지 않음
- `status`와 `boot-id`는 이름 없이 통과. 이름이 있으면 허용 목록 검사

**완료**

- [x] 목록 밖 동사는 거부
- [x] 허용 목록 밖 이름은 거부
- [x] 추가 인자는 거부
- [x] 거부된 입력은 명령으로 실행되지 않음

### 3.4 `status`와 `boot-id`

**구현**

- `status`: 호스트 기본 정보. 지금의 `hostname`, `uptime`, `whoami`. 읽기 전용
- 추가: `boot-id`. 부팅마다 바뀌는 값 한 줄. 읽기 전용
- 두 동사 모두 파일 변경, 서비스 정지, 패키지 설치 없음
- `gostodian run`이 보내는 동사는 `status`. `boot-id`는 게이트가 받을 수 있는 동사로만 둠

**완료**

- [x] `status` 결과가 이력
- [x] `boot-id`는 값 출력만. 호스트 상태 변경 없음
- [x] `status` 외 동사를 `gostodian run`이 보내지 않음
