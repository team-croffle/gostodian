# v0.3.0 (알림)

기준: `Doc/RoadMap_v1.md`의 v0.3.0  
출발점: v0.2.0

## 1. 목표

점검 머신에서 `gostodian run`이 끝나면 점검 결과와 접속 실패가 Discord로 간다. 전송이 실패해도 점검은 멈추지 않고, 실패는 로컬 이력에 남는다. 원문 로그는 Discord에 없다.

## 2. 구현 내용

- Discord 웹훅: 점검 시작·완료·실패, 접속 실패 분류. 원문 로그 제외
- 전송 실패 시 로컬 로그만. 점검은 계속

## 3. 상세 구현 내용

### 3.1 Discord 웹훅

**구현**

- 유지: `secrets.discord_webhook_file`와 컨테이너 마운트. env에는 경로만
- 추가: 그 파일의 웹훅으로 전송. 점검 시작, `status` 완료, 점검 실패, 접속 실패 분류(`auth_failed`, `host_unreachable`, `host_key_mismatch`, `vpn_required`)
- 유지: 메시지에 원문 로그와 시크릿 본문 없음

**완료**

- [x] `status` 결과가 Discord
- [x] 홈랩 꺼짐 또는 VPN 끊김에도 분류된 실패 알림
- [x] 메시지에 원문 로그와 웹훅 URL 본문 없음

### 3.2 전송 실패

**구현**

- 추가: 웹훅 전송 실패는 로컬 이력에만 기록
- 유지: 전송 실패가 점검 결과를 실패로 바꾸지 않음

**완료**

- [x] 웹훅이 거절되어도 점검 이력은 남고 `gostodian run`은 점검 결과로 끝남
